https://thunderstore.io/c/repo/p/ChaosTricks/ChaosTricks_REPO_TwitchIntegration/

python -m pip install websockets asyncio

python -m pip install -r requirements.txt

just run game with CT mode (and others) with host mode, then run websockets.py and see magic of random
